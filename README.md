# Расписание ресторана — restaurant-schedule-app

Мобильное PWA для управления недельным расписанием официантов и посудомойщиков.

> Проект в разработке поэтапно. Этот README будет дополнен полными
> инструкциями (запуск, деплой, переменные окружения, push-уведомления)
> к концу Этапа 6. Пока что — по мере готовности каждого этапа.

## Статус этапов

- [x] Этап 1: проект, БД, пользователи, админ, языки, базовый интерфейс
- [x] Этап 2: расписание, временные интервалы, потребности, расчёт покрытия
- [x] Этап 3: дефицит, запросы сотрудникам, приоритет посудомойщика
- [x] Этап 4: push-уведомления
- [ ] Этап 5: приход/уход, история, ручное редактирование админом
- [ ] Этап 6: PWA, мобильная оптимизация, тесты, деплой
